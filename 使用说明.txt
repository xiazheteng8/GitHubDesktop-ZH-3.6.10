GitHub Desktop 3.6.10 简体中文补丁 · 全面汉化测试版

安装
1. 将 ZIP 完整解压到一个文件夹，不要只运行压缩包里的脚本。
2. 完全退出 GitHub Desktop。
3. 双击 install.cmd，成功后重新打开 GitHub Desktop。
4. 恢复英文时，完全退出 GitHub Desktop，再双击 restore.cmd。

默认安装目录：%LOCALAPPDATA%\GitHubDesktop
自定义安装路径示例（在 PowerShell 中执行）：
.\patch.ps1 -InstallPath 'D:\GitHubDesktop'
.\patch.ps1 -InstallPath 'D:\GitHubDesktop' -Restore
仅检查兼容性，不修改文件：
.\patch.ps1 -VerifyOnly

兼容性
仅适配此次提供的 Windows GitHub Desktop 3.6.10 原始文件。
同版本的其他构建如果文件校验不一致，也会拒绝安装。
3.6.4 的旧补丁不能混用。官方后续更新需要重新生成和验证。

原文件保存在 app-3.6.10\resources\app\.zh-original-3.6.10 中，请保留。
备份校验异常、版本不符或文件被其他工具修改时，安装器会停止。
安装器不会强制关闭应用，不会改仓库内容、账户和网络设置。
不要删除原始备份，尤其是在确认补丁可正常使用之前。

词库与源码
词库.json：基础词库与本次追加文案。
translation-report.json：每条实际匹配文案、来源、替换次数及保留候选。
source/build.cjs：基于原始文件重新生成补丁，需要 Node.js 22 或更高版本。
在补丁文件夹中执行：
node source/build.cjs '原始 app-3.6.10\resources\app 路径' '输出文件夹'
生成器会校验输出与本包已审核补丁是否一致。
若修改词库，需要重新评审并更新校验清单，不能直接绕过文件保护。
